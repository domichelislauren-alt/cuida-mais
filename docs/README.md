# CUIDA+ - v5

## Melhorias
- bairro e unidade agora são campos editáveis com sugestões via datalist
- 31 UPAs da cidade do Rio de Janeiro consolidadas (municipais e estaduais)
- serviço específico `Urgência / UPA 24h`, sem agendamento de horário
- unidades de Atenção Primária e vacinação mantidas separadamente
- múltiplas unidades por bairro aparecem como sugestões
- layout responsivo para computador e celular
