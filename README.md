# CUIDA+

Projeto acadêmico de **Inclusão Digital e Acesso à Saúde**.

## Publicação no GitHub Pages

1. Crie um repositório no GitHub, por exemplo: `cuida-mais`.
2. Envie todo o conteúdo desta pasta para a raiz do repositório.
3. No GitHub, acesse **Settings > Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Selecione a branch **main** e a pasta **/(root)**.
6. Clique em **Save**.
7. Aguarde alguns minutos. O endereço ficará no formato:
   `https://SEU-USUARIO.github.io/cuida-mais/`

## Observações técnicas

- O projeto é estático: HTML, CSS e JavaScript.
- O GitHub Pages não precisa de servidor ou banco de dados para esta versão.
- Os dados de `localStorage` ficam salvos apenas no navegador/dispositivo do usuário.
- Para sincronizar agendamentos entre usuários/dispositivos, futuramente será necessário um backend/banco de dados.
